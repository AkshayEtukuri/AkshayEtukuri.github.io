AI-IDS — Transformer vs. Tabular for Intrusion Detection

A research-driven capstone comparing a custom PyTorch transformer against a Random Forest baseline on the CICIDS2017 network intrusion dataset (2.52M rows). Built a leakage-free pipeline that uncovered and fixed a critical deduplication bug (10.88% exact-duplicate rows inflating results to a suspicious 100%), then trained both models honestly: Random Forest reached 99.87% accuracy vs. the transformer's 98.89% on a CPU-constrained sample. Extracted per-attack attention weights to interpret what the transformer actually learned, flagging spurious signals rather than overselling them.

AI-IDS — Sequence-Aware Intrusion Detection Capstone

Capstone project testing whether restructuring network flow features as an ordered sequence and modeling them with a transformer outperforms standard tabular modeling for intrusion detection. Built a full data pipeline on CICIDS2017 (2.8M+ rows) — including catching and fixing a 10.88% train/test leakage issue from duplicate flow records — then trained a leakage-free Random Forest baseline (99.87% accuracy) against a custom transformer with chunked sequence representation (98.89% accuracy), plus an attention-based interpretability layer showing which feature groups the model relied on per attack type. Packaged with Docker for reproducible inference.
